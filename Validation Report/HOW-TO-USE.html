4. Troubleshooting

Application Not Found

Solution:
- Verify application is installed
- Match name exactly from Programs & Features
- Try shorter name (e.g., "Adobe" vs "Adobe Reader DC")

UAC Prompt Cancelled

Solution:
- Must click "Yes" on UAC prompt
- Admin rights required for registry access
- Run tool again and approve elevation

Snagit Not Responding

Solution:
- Ensure Snagit is installed and running
- Close other Snagit windows first
- Wait after tool minimizes before capturing
- Verify Snagit 2021 or later installed

Template File Not Found

Solution:
- Run from tool directory
- Keep folder structure intact
- Verify templates\Professional-Validation-Template.html exists

5. Tips for Best Results

Before Running:
+ Install target application completely
+ Close unnecessary windows
+ Have Snagit ready
+ Know exact app name from Programs & Features
During Captures:
+ Wait for Snagit to activate
+ Capture entire relevant area
+ Include context (full windows)
+ Expand Start Menu folders to show all shortcuts
After Generation:
+ Review report for accuracy
+ Verify screenshots are clear
+ Check installation details complete
+ Save or share HTML file
